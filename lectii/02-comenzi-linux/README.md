# Lecția 2 — Comenzi Linux (SO.lab)

Lecție practică: navigare, fișiere, directoare, căutare (`find`/`grep`) și redirectare, cu terminale simulate.

## Deschidere

Deschide `index.html` în browser.

## Regenerare

```powershell
.\build.ps1
```

## Conținut

- Teorie scurtă: căi, `~`, case-sensitive, ierarhia de bază
- Comenzi: `pwd`, `cd`, `ls`, `mkdir`, `touch`, `cp`, `mv`, `rm`, `cat`, `head`, `tail`, `find`, `grep`, `>`, `>>`, `|`, `du`/`df`/`wc`, `whoami`/`chmod`/`sudo`
- Q&A + tabel punte către Windows (lecția 3)
